# AngelLog 🎣

AngelLog ist eine mobile PWA für Angler.

## Aktuelle Funktionen
- Gewässer per Namen suchen
- Karte mit Angelspots
- DAV/LAV-Status und Gewässernummer speichern
- Fangbuch mit Fischart, Größe, Gewicht, Köder und Methode
- Registrierung und Login über Supabase
- Cloud-Synchronisierung zwischen iPhone, Android und PC
- Installierbar als PWA

## Technik
- Frontend: HTML/CSS/JavaScript
- Karten: Leaflet + OpenStreetMap
- Gewässersuche: Photon/OpenStreetMap
- Backend/Auth: Supabase
- Hosting: Vercel

Aktuelle Version: **v4 Cloud**
